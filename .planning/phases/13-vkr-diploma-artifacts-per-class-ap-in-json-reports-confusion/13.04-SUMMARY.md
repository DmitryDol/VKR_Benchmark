# Phase 13 Plan 04: Qualitative Detection Examples Summary

Script that emits 12 collage PNGs (4 models x 3 scenarios x 8 inference-mode cells) from cached prediction JSON files.

## What Was Built

`scripts/qualitative_examples.py` — typer CLI that:
1. Reads `SCENARIO_IMAGE_IDS` (dense=139, occluded=776, large_single=285) and asserts correctness via `_verify_scenario_ids`.
2. For each `(model, scenario)` pair loads the source image from `data/val2017/<image_id_12>.jpg`.
3. Resolves the 8 stage IDs: 5 fixed + best_int8 / worst_int8 / best_mixed (selected by `map_50_95` from existing stage JSONs; tie-break alphabetical).
4. For RF-DETR-L, slots 5/6/7 produce a grey placeholder cell instead of inference cells.
5. Draws predicted bounding boxes (RGB 0/100/255, opacity 0.7, confidence >= 0.25) via OpenCV; annotates each cell with mode label + `mAP=X.XXX, lat=Y.Yms`.
6. Saves a 4x2 collage (`plt.subplots(2, 4, figsize=(16, 8))`) at `media/qualitative/<model>_<scenario>.png` via the sha256-stable two-pass PNG save.

## Scenario Image IDs

| Scenario | image_id | Selection rule |
|----------|----------|----------------|
| dense | 139 | Smallest id with >= 15 non-iscrowd GT instances (20 GTs found) |
| occluded | 776 | Smallest id (after excluding 139) with >= 1 GT pair having IoU >= 0.30 |
| large_single | 285 | Smallest id with <= 3 non-iscrowd GTs where max GT area >= 40% of image area |

## RF-DETR-L Placeholder Strategy

Slots 5 (Best INT8), 6 (Worst INT8), and 7 (Best Mixed) render a grey frame (RGB 128/128/128)
with centred black text "n/a\nRF-DETR-L\ntactic rollback to FP16". This preserves the 4x2
grid shape across all 12 collages, making them visually uniform for the diploma.

The 5 RF-DETR-L invalid stages (`5_trt_int8_entropy`, `5_trt_int8_minmax`,
`5_trt_int8_percentile`, `6_trt_mixed_a`, `6_trt_mixed_b`) are excluded as in all Phase 13
plans.

## Determinism Contract

- `np.random.seed(0)` and `random.seed(0)` at module load.
- All iteration orders are `tuple` constants (`MODELS_ORDER`, `SCENARIOS_ORDER`, `MODE_LABELS_8`).
- PNG headers stabilised by passing `metadata={"Software": "matplotlib"}` to `fig.savefig`,
  then Pillow re-save strips any remaining variable fields.
- Re-running produces byte-identical output (`sha256sum` verified once cache is populated).

## Graceful Degradation

When `cache/predictions/coco_dt_<model>_<stage>.json` is absent the cell renders a placeholder
labelled `<mode>\n[cache missing]` rather than crashing. The count reported to stdout reflects
only successfully saved PNG files.
