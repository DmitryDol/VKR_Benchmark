# Quick Task 260510-a01: Fix Windows Backslash Path — rtdetr_adapter.py

## Root Cause

`RTDetrForObjectDetection.from_pretrained(str(weights_path))` on Windows:
- `str(Path("weights/rtdetr-r50/"))` → `"weights\rtdetr-r50"` (backslashes)
- HuggingFace hub interprets this as a repo ID, rejects it: `HFValidationError: Repo id must use alphanumeric chars, '-', '_' or '.'`

## Fix

### Task T01: Fix rtdetr_adapter.py line 180

**File:** `src/benchmark/models/rtdetr_adapter.py`
**Action:** modify
**Line:** ~180 — `model = RTDetrForObjectDetection.from_pretrained(str(weights_path))`
**Change:** Use `weights_path.resolve()` instead of `weights_path` to produce an absolute path that HuggingFace recognizes as a local directory.

```python
# Before
model = RTDetrForObjectDetection.from_pretrained(str(weights_path))

# After
model = RTDetrForObjectDetection.from_pretrained(str(weights_path.resolve()))
```

**Done:** `ruff check src/benchmark/models/rtdetr_adapter.py` exits 0
