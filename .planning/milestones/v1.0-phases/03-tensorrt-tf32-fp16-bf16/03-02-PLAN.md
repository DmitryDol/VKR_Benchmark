## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI --engine-dir flag → filesystem | User-supplied path used for .engine file I/O |
| CLI --stage flag → stage dispatch | String matched against known stage IDs |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Tampering | --engine-dir path traversal | mitigate | engine_dir is derived from output_dir which cli.py resolves via Path(...).resolve() (existing T-02-05). Apply same resolve() to engine_dir before passing to TensorRTEngine. |
| T-03-07 | Spoofing | Unknown --stage value | mitigate | `else: raise typer.BadParameter` rejects unknown stage IDs; only STAGE_REGISTRY values dispatched. |
| T-03-08 | Denial of Service | BF16 skipped result polluting CSV | accept | skipped_reason column self-documents the skip; NaN values in numeric columns are standard IEEE representation. Downstream analysis tools handle NaN gracefully. |
</threat_model>
