## Matching Algorithm

Greedy IoU matching per image, applied over the union of GT and prediction image_id sets:

1. Group predictions by `image_id`.
2. Iterate `sorted(set(gt_by_image) | set(pred_by_image))` — union guarantees:
   - Images with GT but no predictions: unmatched GTs go to `matrix[gt_class, background]`.
   - Images with predictions but no GT: predictions go to `matrix[background, pred_class]`.
3. For each image: filter predictions by `score >= 0.25`, sort descending.
4. Greedy match each prediction to the highest-IoU unmatched GT with `iou >= 0.5`.
5. Matched pair increments `matrix[gt_class_idx, pred_class_idx]`.
6. Unmatched prediction → `matrix[background=80, pred_class_idx]`.
7. Unmatched GT → `matrix[gt_class_idx, background=80]`.

Matrix shape: `(81, 81)` int64 before normalization.

## Supercategory Mapping Derivation

`_load_categories()` reads `categories[].supercategory` from `instances_val2017.json` and maps each of the 80 COCO class indices (sorted ascending by COCO id) to the index into the locked `SUPERCATEGORIES` 12-tuple. The background virtual class (index 80) always maps to supercategory index 12 in `aggregate_to_supercat_12()`. The resulting `(13, 13)` matrix sums all `(gt_supercat, pred_supercat)` pairs from the `(81, 81)` source matrix.

## PNG Metadata Strategy (sha256 Stability)

Two-layer approach inside `render_confusion_png`:

1. **matplotlib layer:** `fig.savefig(..., metadata={"Software": "matplotlib"})` suppresses the variable software-version field that matplotlib writes by default.
2. **PIL strip (unconditional):** After `fig.savefig`, the PNG is re-opened via `with Image.open(path) as im: im.save(path, "PNG", optimize=False)`. PIL's default PNG writer strips all metadata chunks except the IDAT stream. `optimize=False` prevents zlib-level variation across runs.

This two-layer approach guarantees byte-identical output on re-runs from the same input matrix.
