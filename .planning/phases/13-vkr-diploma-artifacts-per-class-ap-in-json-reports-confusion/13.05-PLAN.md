**Module-level setup:**
- `from __future__ import annotations`
- `import cv2`, `import numpy as np`.
- `np.random.seed(0); random.seed(0)` at module load.

**Hardcoded image_ids (LOCKED in the script via a sorted tuple):**
```
# 9 image_ids — ONE per supercategory bin per advisor spec.
# Order in the tuple is SORTED ASCENDING by image_id (defines the LEFT-TO-RIGHT,
# TOP-TO-BOTTOM grid order).
# Deterministic precomputed via Python one-liner against
# data/annotations/instances_val2017.json on 2026-05-19 with these rules:
#   For each supercategory bin, pick the smallest image_id with >=2 non-iscrowd GT
#   matching the bin (see hint comment). Tie-break: when two bins map to the same
#   smallest image_id, keep it for the bin that lists it first below; the other
#   bin uses the NEXT-smallest distinct image_id matching its rule.
SAMPLE_IMAGE_IDS: tuple[tuple[int, str], ...] = (
    (139,  "furniture: chairs + dining table"),
    (724,  "outdoor (no person): outdoor signage"),
    (872,  "sports: >=2 sports-supercat GTs"),
    (1268, "person + vehicle: street scene"),
    (1503, "electronic: >=2 electronic-supercat GTs (next-smallest after 139 to keep 9 ids unique)"),
    (1818, "animal: >=2 animal-supercat GTs"),
    (2157, "kitchen: >=2 kitchen-supercat GTs"),
    (2587, "food: >=2 food-supercat GTs"),
    (5001, "indoor + accessory: at least 1 each"),
)
```
The hardcoded tuple above is the FINAL locked selection — DO NOT substitute. A startup helper `_verify_sample_ids(coco_json)` re-asserts the per-bin properties via plain `assert` statements (NOT `typer.Exit`); if any assertion fails it indicates the annotations file diverged from the 2026-05-19 baseline and is a developer-time failure, not a runtime fallback.

**Drawing constants:**
```
TILE_W: int = 500
TILE_H: int = 400
GRID_ROWS: int = 3
GRID_COLS: int = 3
TILE_SPACING_PX: int = 6
# Canvas = (3*400 + 4*6, 3*500 + 4*6, 3) = (1224, 1524, 3)
# height 1224, width 1524, ~= spec target 1500 x 1200
GT_COLOR_BGR: tuple[int, int, int] = (0, 200, 0)   # OpenCV BGR == RGB (0, 200, 0)
GT_THICKNESS: int = 2
LABEL_FONT: int = cv2.FONT_HERSHEY_SIMPLEX
LABEL_SCALE: float = 0.5
LABEL_THICKNESS: int = 1
```

**Helper functions:**

- `_image_path(image_id: int, images_dir: Path) -> Path` → returns `images_dir / f"{image_id:012d}.jpg"`.

- `_load_gt_for_image(image_id: int, coco_json: dict[str, object]) -> list[tuple[int, str, list[float]]]`:
  - Returns a list of `(category_id, class_name, xywh_bbox)` for all non-iscrowd GT in the given image.
  - The `coco_json` dict is the loaded `instances_val2017.json`.

- `_letterbox_fit(image_bgr: np.ndarray, target_w: int, target_h: int) -> tuple[np.ndarray, tuple[float, float, float, float]]`:
  - Resizes preserving aspect; pads with black to exactly `target_w × target_h`.
  - Returns `(resized_padded_image, (scale_x, scale_y, pad_x, pad_y))` so the caller can transform bbox coordinates.
  - Use a SINGLE scale factor (`min(target_w/orig_w, target_h/orig_h)`) so the bbox transform is `(x' = x*scale + pad_x, y' = y*scale + pad_y, w' = w*scale, h' = h*scale)`.

- `_draw_gt(image_bgr: np.ndarray, gt: list[tuple[int, str, list[float]]], transform: tuple[float, float, float, float]) -> None`:
  - For each `(cat_id, class_name, [x, y, w, h])`:
    - Transform coords with `transform`.
    - `cv2.rectangle(image_bgr, (x1,y1), (x2,y2), GT_COLOR_BGR, GT_THICKNESS)`.
    - Label plate: compute `(tw, th), _ = cv2.getTextSize(class_name, LABEL_FONT, LABEL_SCALE, LABEL_THICKNESS)`; `cv2.rectangle(image_bgr, (x1, y1 - th - 4), (x1 + tw + 4, y1), GT_COLOR_BGR, -1)`; `cv2.putText(image_bgr, class_name, (x1 + 2, y1 - 3), LABEL_FONT, LABEL_SCALE, (255,255,255), LABEL_THICKNESS, cv2.LINE_AA)`.

- `_assemble_grid(tiles_bgr: list[np.ndarray]) -> np.ndarray`:
  - Allocates a single canvas of size `(GRID_ROWS * TILE_H + (GRID_ROWS + 1) * TILE_SPACING_PX, GRID_COLS * TILE_W + (GRID_COLS + 1) * TILE_SPACING_PX, 3)`, filled with white (255,255,255).
  - Pastes each tile at its grid position.
  - Returns the canvas.

**CLI command:**
```
@app.command()
def main(
    images_dir: Path = typer.Option(Path("data/val2017"), "--images-dir"),
    annotations: Path = typer.Option(Path("data/annotations/instances_val2017.json"), "--annotations"),
    out_path: Path = typer.Option(Path("media/coco_val2017_samples.png"), "--out"),
) -> None:
```

**Algorithm:**
1. `out_path.parent.mkdir(parents=True, exist_ok=True)`.
2. Load `coco_json = json.loads(annotations.read_text(encoding="utf-8"))` ONCE.
3. Build `class_names_by_id = {c["id"]: c["name"] for c in coco_json["categories"]}`.
4. Verify each of the 9 image_ids: confirm `_image_path(...).exists()` and that GT exists (at least 1 annotation).
5. For each of the 9 `(image_id, hint)` tuples:
   - `image = cv2.imread(str(_image_path(image_id, images_dir)))`.
   - `gt = _load_gt_for_image(image_id, coco_json)` (resolve class_name via `class_names_by_id`).
   - `tile, transform = _letterbox_fit(image, TILE_W, TILE_H)`.
   - `_draw_gt(tile, gt, transform)`.
6. `canvas = _assemble_grid(tiles_bgr)`.
7. Write the canvas via `cv2.imwrite(str(out_path), canvas)` — but `cv2.imwrite` for PNG does NOT include timestamps by default (good for determinism). Confirm via a sha256 cross-run check; if it differs, re-open with PIL and resave with `Image.open(out_path).save(out_path, "PNG", optimize=True)` as a metadata-strip safety net.

**Determinism:**
- All iteration order is from the locked tuple.
- All drawing constants are integers / floats from locked constants.
- No matplotlib, no random.
- The Pillow safety re-save is unconditional.
