# Quick Task 260510-a01: Fix Windows Backslash Path in RTDETRAdapter

One-liner: Replaced `str(weights_path)` with `str(weights_path.resolve())` so HuggingFace `from_pretrained` receives an absolute POSIX-compatible path on Windows instead of a backslash-separated relative path.

## Root Cause

On Windows, `str(Path("weights/rtdetr-r50/"))` produces `"weights\rtdetr-r50"`. HuggingFace `from_pretrained` interprets this as an invalid Hub repo ID and raises an error. Using `.resolve()` converts to an absolute path (`C:\projects\...\weights\rtdetr-r50`) which HuggingFace correctly identifies as a local directory.

## Fix

**File:** `src/benchmark/models/rtdetr_adapter.py`, line 180

Before:
```python
model = RTDetrForObjectDetection.from_pretrained(str(weights_path))
```

After:
```python
model = RTDetrForObjectDetection.from_pretrained(str(weights_path.resolve()))
```
