Create `src/benchmark/eval/confusion.py` with `from __future__ import annotations`, module-level `logger`, and the following public API:

**Module-level constants:**
- `IOU_THRESHOLD: float = 0.5`
- `CONFIDENCE_THRESHOLD: float = 0.25`
- `SUPERCATEGORIES: tuple[str, ...] = ("person", "vehicle", "outdoor", "animal", "accessory", "sports", "kitchen", "food", "furniture", "electronic", "appliance", "indoor")` — exact order locked in CONTEXT.md.

**Function `_iou_xywh(box_a: tuple[float, float, float, float], box_b: tuple[float, float, float, float]) -> float`:**
- Computes IoU between two xywh boxes. Convert to (x1,y1,x2,y2), compute intersection-area / union-area. Return 0.0 if union is 0.

**Function `build_confusion_80(predictions: list[dict[str, object]], gt_by_image: dict[int, list[dict[str, object]]], category_id_to_idx: dict[int, int], num_classes: int = 80) -> np.ndarray`:**
- Input `predictions` is the list from a cached `coco_dt_*.json`.
- Input `gt_by_image` maps image_id → list of GT annotation dicts (`{"category_id": int, "bbox": [x,y,w,h], "iscrowd": int}`); iscrowd==1 entries MUST be excluded from matching.
- Input `category_id_to_idx` maps COCO-91 native ID → 0..79 contiguous index. Build this from `data/annotations/instances_val2017.json::categories` sorted by `id` ascending. The "background" virtual class has index 80.
- Greedy IoU matching algorithm (UNION-OF-IMAGE-IDS — both GT and predictions contribute, even when one side is empty):
  0. Compute `pred_by_image: dict[int, list[dict]]` by grouping `predictions` on `image_id`.
  1. Iterate `all_image_ids = sorted(set(gt_by_image) | set(pred_by_image))` — this guarantees images with ≥1 GT but 0 predictions contribute their unmatched GTs to the `background` column, AND images with predictions but no GT contribute their false positives to the `background` row.
  2. For each `image_id` in that sorted union: fetch `gt_list = gt_by_image.get(image_id, [])` and `pred_list = pred_by_image.get(image_id, [])`.
  3. Filter `pred_list` by `score >= CONFIDENCE_THRESHOLD`. Sort surviving predictions by descending score.
  4. Track `matched_gt: set[int]` (indices into the image's GT list).
  5. For each prediction (in sorted order): find the best unmatched GT (highest IoU) where `iou >= IOU_THRESHOLD`. If found, increment `matrix[gt_class_idx, pred_class_idx]` and add GT to matched. If no match, increment `matrix[BACKGROUND, pred_class_idx]`.
  6. After all predictions: for each unmatched GT in `gt_list`, increment `matrix[gt_class_idx, BACKGROUND]`.
  7. The SAME `sorted(set(gt_by_image) | set(pred_by_image))` iteration order MUST be used by both `build_confusion_80` and (transitively, since `aggregate_to_supercat_12` only reshapes a precomputed 81×81 matrix) the supercategory aggregator.

**Acceptance criterion (union iteration):** Images with ≥1 GT and 0 predictions contribute to the `background` column (unmatched GT → `matrix[gt_class, background_index]`). Images with predictions and 0 GT contribute to the `background` row (every prediction → `matrix[background_index, pred_class]`).
- Matrix shape `(num_classes + 1, num_classes + 1)` (81×81 — extra row/col for background).
- Return `np.ndarray` of shape `(81, 81)` dtype `int64`. Do NOT row-normalize here; the caller decides whether to render the raw counts or the row-normalized matrix.

**Function `aggregate_to_supercat_12(matrix_80: np.ndarray, idx_to_supercat: dict[int, int]) -> np.ndarray`:**
- `idx_to_supercat` maps 0..79 → 0..11 (index into `SUPERCATEGORIES`). The background row/col at index 80 maps to index 12 (also called "background").
- Sum 80×80 cells into a 12×12 aggregate; background stays a separate row/col → returned shape `(13, 13)` dtype `int64`.

**Function `row_normalize(matrix: np.ndarray) -> np.ndarray`:**
- Returns a float64 copy where each row sums to 1.0; rows whose original sum is 0 are emitted as all-zeros (do NOT divide by zero — use `np.where(row_sum > 0, row / row_sum, 0)`).

**Function `render_confusion_png(matrix_norm: np.ndarray, class_labels: list[str], title: str, output_path: Path, figsize_in: tuple[float, float], annotate_cells: bool) -> None`:**
- Renders `matrix_norm` with `matplotlib.pyplot.imshow(matrix_norm, cmap="viridis", vmin=0.0, vmax=1.0)`.
- Ticks: x-axis labels at every position, rotated 45° right-aligned, fontsize 6 for the 80×80 case, fontsize 9 for the 12×12 case.
- Cell annotations (`annotate_cells=True` only for the 12×12 case): write the float value at each cell, white text if cell value > 0.5 else black, fontsize 7, `ha="center", va="center"`.
- Title in English at fontsize 11, suptitle uses `title` argument verbatim.
- Add colorbar via `plt.colorbar(im, fraction=0.046, pad=0.04)`.
- `plt.tight_layout(); fig.savefig(str(output_path), dpi=120, bbox_inches="tight"); plt.close(fig)`.
- The 12×12 figsize SHOULD be approximately `(7, 6)` inches; the 80×80 figsize SHOULD be approximately `(14, 13)` inches.
- Determinism: matplotlib's `Figure.savefig` writes a timestamp into PNG metadata by default; set `matplotlib.rcParams["svg.hashsalt"]` is irrelevant for PNG, but `matplotlib.rcParams["pdf.compression"]` is also irrelevant. **Module-level setup:**

- `import matplotlib; matplotlib.use("Agg")` BEFORE any other matplotlib import (headless rendering).

Pick duplication — explicit is determinism-friendly.

**Helper functions (module-private, prefixed `_`):**
- `_load_categories(annotations_path: Path) -> tuple[dict[int, int], list[str], dict[int, int]]`:
  - Loads `instances_val2017.json::categories`.
  - Sorts by `id` ascending.
  - Returns `(category_id_to_idx, class_names_80, idx_to_supercat_idx)`.
  - `class_names_80`: list of 80 names in the sorted order.
  - `idx_to_supercat_idx`: 0..79 → 0..11 (index into `SUPERCATEGORIES`).
- `_load_gt_by_image(annotations_path: Path) -> dict[int, list[dict[str, object]]]`:
  - Loads `instances_val2017.json::annotations`, groups by `image_id`, filters out `iscrowd==1` entries (per CONTEXT.md confusion semantics).
- `_supercat_labels() -> list[str]` returns `[*SUPERCATEGORIES, BACKGROUND_LABEL]` (length 13).
- `_full_labels(class_names_80: list[str]) -> list[str]` returns `[*class_names_80, BACKGROUND_LABEL]` (length 81).

**CLI command:**
```
@app.command()
def main(
    models: list[str] = typer.Option(["rt-detr", "yolo11l", "yolo26l", "rfdetr-l"], "--model", "-m"),
    stages: list[str] | None = typer.Option(None, "--stage", "-s"),
    results_root: Path = typer.Option(Path("results"), "--results-root"),
    cache_root: Path = typer.Option(Path("cache/predictions"), "--cache-root"),
    annotations: Path = typer.Option(Path("data/annotations/instances_val2017.json"), "--annotations"),
    out_12: Path = typer.Option(Path("media/confusion_12"), "--out-12"),
    out_80: Path = typer.Option(Path("results/confusion_80"), "--out-80"),
) -> None:
```

**Algorithm:**
1. `out_12.mkdir(parents=True, exist_ok=True); out_80.mkdir(parents=True, exist_ok=True)`.
2. Load categories once: `(cat_id_to_idx, class_names_80, idx_to_super) = _load_categories(annotations)`.
3. Load GT once: `gt_by_image = _load_gt_by_image(annotations)`.
4. Resolve stage list: default = `STAGE_REGISTRY` imported from `benchmark.cli`; user override via `--stage` (repeated).
5. Iterate `(model, stage)` in deterministic order. Skip `(rfdetr-l, stage)` if in `RFDETR_L_INVALID_STAGES`.
6. For each pair:
   a. `cache_path = cache_root / f"coco_dt_{model}_{stage}.json"`. If missing → log warning and skip.
   b. `predictions = json.loads(cache_path.read_text(encoding="utf-8"))`.
   c. `matrix_80_counts = build_confusion_80(predictions, gt_by_image, cat_id_to_idx)`.
   d. `matrix_12_counts = aggregate_to_supercat_12(matrix_80_counts, idx_to_super)`.
   e. `matrix_80_norm = row_normalize(matrix_80_counts)`.
   f. `matrix_12_norm = row_normalize(matrix_12_counts)`.
   g. Read `map_50_95` from `results/<model>/<VARIANT_DIRS[model]>/<stage>.json`.
   h. Title: `f"Confusion 12x12 — {model} / {stage} / mAP@0.5:0.95 = {map_50_95:.3f}"` for the 12×12 and likewise for 80×80.
   i. `render_confusion_png(matrix_12_norm, _supercat_labels(), title_12, out_12 / f"{model}_{stage}.png", (7.0, 6.0), annotate_cells=True)`.
   j. `render_confusion_png(matrix_80_norm, _full_labels(class_names_80), title_80, out_80 / f"{model}_{stage}.png", (14.0, 13.0), annotate_cells=False)`.
7. Print summary: counts of `(rendered, skipped_missing_cache, skipped_excluded)`.

**Determinism:** Module-level `np.random.seed(0); random.seed(0)`. Matplotlib's PNG metadata is suppressed inside `render_confusion_png` (Task 1). The `(model, stage)` iteration order is fixed by `CLI default arg order × STAGE_REGISTRY order`. No filesystem globs.

**Performance note (informational, not a constraint):** Building the 80×80 matrix for one config touches ~5000 images × ~10-300 detections per image = ~10^6 IoU computations. Use NumPy where possible (vectorize per-image IoU); per-image greedy match is acceptable.
