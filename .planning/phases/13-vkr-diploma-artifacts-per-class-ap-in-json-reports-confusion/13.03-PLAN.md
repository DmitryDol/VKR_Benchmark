Create `scripts/per_class_summary.py` — typer CLI that consumes the `per_class_ap` field from the 35 valid stage JSONs and emits per-model summary tables.

**Module-level setup:**
- `from __future__ import annotations`
- `np.random.seed(0); random.seed(0)` at module load.
- Module-level logger.
- Hardcoded constants:
  ```
  MODELS_ORDER: tuple[str, ...] = ("rt-detr", "yolo11l", "yolo26l", "rfdetr-l")
  VARIANT_DIRS: dict[str, str] = {
      "rt-detr": "quant",
      "yolo11l": "quant",
      "yolo26l": "quant",
      "rfdetr-l": "rfdetr_v1",
  }
  RFDETR_L_INVALID_STAGES: frozenset[str] = frozenset({
      "5_trt_int8_entropy", "5_trt_int8_minmax", "5_trt_int8_percentile",
      "6_trt_mixed_a", "6_trt_mixed_b",
  })
  # Column → stage mapping (ordered): the COLUMN order defines the OUTPUT order
  COLUMN_TO_STAGE: tuple[tuple[str, str], ...] = (
      ("AP_FP32",            "1_pytorch_fp32"),
      ("AP_TF32",            "3_trt_tf32"),
      ("AP_FP16",            "4_trt_fp16"),
      ("AP_BF16",            "4_trt_bf16"),
      ("AP_INT8_Entropy",    "5_trt_int8_entropy"),
      ("AP_INT8_MinMax",     "5_trt_int8_minmax"),
      ("AP_INT8_Percentile", "5_trt_int8_percentile"),
      ("AP_Mixed1",          "6_trt_mixed_a"),
      ("AP_Mixed2",          "6_trt_mixed_b"),
  )
  ```

**Helper functions:**

- `_load_per_class(model: str, stage: str, results_root: Path) -> dict[int, dict[str, object]] | None`:
  - Returns `None` if the stage JSON is missing OR if `per_class_ap` is empty (signals "data not yet backfilled by P01").
  - Otherwise returns `{class_id: entry}` keyed by `class_id`.

- `_build_table(model: str, results_root: Path) -> tuple[list[str], list[list[object]]]`:
  - Returns `(headers, rows)` where:
    - `headers = ["class_name", "n_gt", *col_names, "min_delta_AP"]` with 12 columns total.
    - `rows`: 80 rows, one per COCO-91 class_id in ascending order.
  - For each class (taken from the FP32 stage's `per_class_ap` — that's the canonical source for `class_id`, `class_name`, `n_gt`):
    - For each `(col_name, stage)` in `COLUMN_TO_STAGE`:
      - If `model == "rfdetr-l"` and `stage in RFDETR_L_INVALID_STAGES`: cell = string `"n/a"`.
      - Else: look up the entry in the per-class list for that stage by `class_id`. Cell = `ap_50_95` float rounded to 3 decimals.
    - Compute `min_delta_AP = min(cell - ap_fp32 for col_name, cell in numeric_cells if col_name != "AP_FP32")` over only the numeric (non-`n/a`) cells.
  - If FP32 stage JSON is missing OR its `per_class_ap` is empty: `raise typer.Exit(code=2)` with a clear message: "FP32 baseline missing or not backfilled — run scripts/build_per_class_ap.py first".

- `_sort_top10_drop(rows: list[list[object]], headers: list[str]) -> list[list[object]]`:
  - Sort by `min_delta_AP` ASCENDING (most-negative = worst drop comes first). Take top 10.

- `_sort_top10_freq(rows: list[list[object]], headers: list[str]) -> list[list[object]]`:
  - Sort by `n_gt` DESCENDING. Take top 10.

- `_write_csv(path: Path, headers: list[str], rows: list[list[object]]) -> None`:
  - Open with `path.open("w", encoding="utf-8-sig", newline="")` (UTF-8 BOM via `utf-8-sig`).
  - `writer = csv.writer(f, delimiter=",", lineterminator="\n")` — explicit `lineterminator="\n"` for sha256 stability across OS.
  - Write headers, then rows. Floats are converted to strings via `f"{x:.3f}"` to lock the precision; `"n/a"` strings pass through.

- `_write_md(path: Path, headers: list[str], rows: list[list[object]]) -> None`:
  - First column (`class_name`) left-aligned (Markdown `:---`).
  - Second column (`n_gt`) and `min_delta_AP` right-aligned (Markdown `---:`).
  - AP columns centered (Markdown `:---:`).
  - Cells: floats formatted to 3 decimals; `"n/a"` passed through.
  - Write with `path.write_text(content, encoding="utf-8")` (no BOM in MD, plain UTF-8); `content` uses `\n` line endings.

**CLI command:**
```
@app.command()
def main(
    models: list[str] = typer.Option(list(MODELS_ORDER), "--model", "-m"),
    results_root: Path = typer.Option(Path("results"), "--results-root"),
    out_csv: Path = typer.Option(Path("results/per_class"), "--out-csv"),
    out_md: Path = typer.Option(Path("media/per_class_md"), "--out-md"),
) -> None:
```

Iterate `models` in CLI order. For each model:
1. `out_csv.mkdir(parents=True, exist_ok=True); out_md.mkdir(parents=True, exist_ok=True)`.
2. `headers, rows = _build_table(model, results_root)`.
3. `drop_rows = _sort_top10_drop(rows, headers)`.
4. `freq_rows = _sort_top10_freq(rows, headers)`.
5. `_write_csv(out_csv / f"{model}_drop_top10.csv", headers, drop_rows)`.
6. `_write_csv(out_csv / f"{model}_freq_top10.csv", headers, freq_rows)`.
7. `_write_md(out_md / f"{model}_drop_top10.md", headers, drop_rows)`.
8. `_write_md(out_md / f"{model}_freq_top10.md", headers, freq_rows)`.

**Determinism contract:**
- Float formatting locked to 3 decimals (`f"{x:.3f}"`).
- CSV `lineterminator="\n"` and Markdown writes use `\n` (no `\r\n`).
- Sort is stable (Python's sort is stable; primary key only — secondary tie-break unnecessary because `class_id` makes rows unique).
- UTF-8 BOM only on CSV (via `encoding="utf-8-sig"`).

## Column-name footnote (for diploma reader)

The column `min_delta_AP` is the most-negative observed delta (`AP_stage - AP_FP32`)
across all valid quantization stages for that class — i.e., the WORST observed drop.
Negative values = drop in accuracy. Positive values would indicate improvement
(unlikely but possible for some FP16/BF16 cases). This should be documented in
`13.03-SUMMARY.md` after execution.
