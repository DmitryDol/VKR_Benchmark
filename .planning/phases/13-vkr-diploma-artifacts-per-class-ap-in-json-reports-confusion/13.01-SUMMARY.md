## Precision-Array Indexing Convention

`COCOeval.eval["precision"]` shape: `[T=10, R=101, K=80, A=4, M=3]`

| Dimension | Meaning | Index used |
|-----------|---------|------------|
| T | IoU threshold (0.50..0.95 step 0.05) | all (`:`) for AP@0.5:0.95; `[0]` for AP@0.5 |
| R | Recall point (0.0..1.0, 101 points) | all (`:`) |
| K | COCO category index (matches `params.catIds`) | `k` per-class loop |
| A | Area range (all / small / medium / large) | `0` (area=all) |
| M | maxDets (1 / 10 / 100) | `2` (maxDets=100) |

Sentinel mask: pycocotools uses `-1` for missing data points; `col[col > -1].mean()` with empty-array guard produces `0.0` when no valid points exist.

`cat_id = coco_eval.params.catIds[k]` gives the COCO-91 native ID. Class name from `coco.cats[cat_id]["name"]`. `n_gt` from `coco.getAnnIds(catIds=[cat_id], iscrowd=False)`.

## Expected User-Side Workflow

1. **One-time slow run (Mode B):** `uv run python scripts/build_per_class_ap.py --live --limit 5000`
   - Loads each of the 35 valid engines, calls `evaluate_accuracy`, writes `cache/predictions/coco_dt_<model>_<stage>.json`, rewrites stage JSON with `per_class_ap` (length 80).
   - Expected runtime: ~24 hours for all 35 configurations on RTX 3070.

2. **Fast re-runs (Mode A, default):** `uv run python scripts/build_per_class_ap.py`
   - Reads the 35 cached JSONs, recomputes `per_class_ap` via `compute_per_class_ap_from_cache`, rewrites stage JSONs in-place. No GPU needed.
   - Deterministic: same cache → byte-identical `per_class_ap` output.

3. **Selective update:** `uv run python scripts/build_per_class_ap.py -m rt-detr -s 1_pytorch_fp32`

4. **Verify:** `python -c "import json; d=json.load(open('results/rt-detr/quant/1_pytorch_fp32.json')); assert len(d['per_class_ap'])==80"`

## Behaviour Change to Existing Pipeline

Every `benchmark run` invocation now writes `cache/predictions/coco_dt_<model>_<stage>.json` as a side effect of `evaluate_accuracy()`. To opt out: `engine.run_full_benchmark(..., cache_predictions=False)`. `cache/` is gitignored.
