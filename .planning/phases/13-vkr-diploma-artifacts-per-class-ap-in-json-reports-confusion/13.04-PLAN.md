**Helper functions:**

- `_image_path(image_id: int, images_dir: Path) -> Path`:
  - Returns `images_dir / f"{image_id:012d}.jpg"`.

- `_pick_best_worst(model: str, results_root: Path) -> tuple[str | None, str | None, str | None]`:
  - Returns `(best_int8_stage, worst_int8_stage, best_mixed_stage)`.
  - For RF-DETR-L: returns `(None, None, None)` (signals: render placeholder).
  - Otherwise: load `results/<model>/<variant>/<stage>.json::map_50_95` for the 3 INT8 stages; pick `best_int8_stage = max by map_50_95`, `worst_int8_stage = min by map_50_95`. Tie-break: alphabetical stage name.
  - Likewise for `best_mixed_stage` from the 2 Mixed stages.

- `_read_predictions(model: str, stage: str, image_id: int) -> list[dict[str, float]]`:
  - Loads `cache/predictions/coco_dt_<model>_<stage>.json`, filters by `image_id`, returns the matching list.

- `_draw_predictions(image_bgr: np.ndarray, preds: list[dict[str, object]], class_names_by_cat_id: dict[int, str]) -> np.ndarray`:
  - Filters by `score >= CONFIDENCE_THRESHOLD`.
  - Draws each xywh box as a translucent rectangle: create `overlay = image_bgr.copy(); cv2.rectangle(overlay, (x,y), (x+w,y+h), BBOX_COLOR_BGR, BBOX_THICKNESS)`; then `cv2.addWeighted(overlay, BBOX_OPACITY, image_bgr, 1 - BBOX_OPACITY, 0, image_bgr)`. For the box BORDER (not fill), use a non-translucent stroke — call `cv2.rectangle(image_bgr, ..., thickness=2)` AFTER blending so the border is solid.
  - Above each box, draw the class name + score (e.g. `"person 0.87"`) with `cv2.FONT_HERSHEY_SIMPLEX`, scale 0.4, thickness 1, anti-aliased, on a solid 2-px-padded background plate.
  - Return the image.

- `_render_cell_axes(ax: plt.Axes, image_rgb: np.ndarray, title: str, subtitle: str) -> None`:
  - `ax.imshow(image_rgb); ax.set_axis_off(); ax.set_title(title, fontsize=9); ax.text(0.5, -0.06, subtitle, transform=ax.transAxes, ha="center", fontsize=8)`.

- `_render_placeholder_axes(ax: plt.Axes, mode_title: str) -> None`:
  - `ax.set_facecolor((0.5, 0.5, 0.5)); ax.set_xticks([]); ax.set_yticks([]); ax.text(0.5, 0.5, "n/a\nRF-DETR-L\ntactic rollback to FP16", transform=ax.transAxes, ha="center", va="center", fontsize=10, color="black"); ax.set_title(mode_title, fontsize=9)`.

**Per-cell algorithm:**
1. Re-verify the precomputed `SCENARIO_IMAGE_IDS` (defense-in-depth assertion ONLY — the ids are locked in code from a deterministic precomputation; the verifier must NEVER substitute a different id). A startup helper `_verify_scenario_ids(annotations)` does:
   - Load `instances_val2017.json::annotations`, group by image_id, compute `len(anns)` (excluding iscrowd==1).
   - `assert` that the chosen `dense` id has ≥15 non-iscrowd GT instances.
   - `assert` that the chosen `large_single` id has ≤3 non-iscrowd GT instances AND at least one with `area >= 0.40 * image.width * image.height`.
   - `assert` that the chosen `occluded` id has ≥2 non-iscrowd GT instances with at least one pair having IoU ≥ 0.30.
   - Use plain `assert` (NOT `typer.Exit`); if any assertion fails it indicates the underlying annotations file diverged from the 2026-05-19 baseline — a developer-time failure, not a runtime fallback.

2. Load `class_names_by_cat_id: dict[int, str]` from `instances_val2017.json`.

3. For each `(model, scenario)` pair:
   - Resolve the 8 stages:
     - Slot 0: `"1_pytorch_fp32"` (PyTorch FP32)
     - Slot 1: `"2_onnx_fp32"` (ONNX FP32)
     - Slot 2: `"3_trt_tf32"` (TRT TF32)
     - Slot 3: `"4_trt_fp16"` (TRT FP16)
     - Slot 4: `"4_trt_bf16"` (TRT BF16)
     - Slot 5: best_int8_stage (or None for RF-DETR-L)
     - Slot 6: worst_int8_stage (or None for RF-DETR-L)
     - Slot 7: best_mixed_stage (or None for RF-DETR-L)
   - Load the source image (`cv2.imread(_image_path(...))`).
   - For each slot:
     - If stage is None (RF-DETR-L only): emit a placeholder axes.
     - Else: load predictions, filter, draw boxes on a fresh image copy, read `map_50_95` and `latency_total_ms` from the stage JSON. Subtitle: `f"mAP={map_50_95:.3f}, lat={latency_total_ms:.1f}ms"`. Title: human-readable mode label (e.g. `"TRT FP16"`).
   - Compose `4×2 grid` (4 cols, 2 rows) via `plt.subplots(2, 4, figsize=(16, 8))`. Slot 0 → (0,0), slot 1 → (0,1), slot 2 → (0,2), slot 3 → (0,3), slot 4 → (1,0), slot 5 → (1,1), slot 6 → (1,2), slot 7 → (1,3).
   - `fig.suptitle(f"{model} — scenario: {scenario} (image_id={image_id})", fontsize=12)`.
   - Save to `out_dir / f"{model}_{scenario}.png"` at dpi=120, bbox_inches="tight", with the same PNG-metadata-strip trick from P02 (`metadata={"Software": "matplotlib"}` + Pillow re-save for sha256-stability).
