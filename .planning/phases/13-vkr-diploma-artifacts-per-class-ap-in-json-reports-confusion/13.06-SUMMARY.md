## Engine Dispatch Reuse Pattern

`_build_engine` dispatches by stage string using the same three maps from `cli.py::_run_stage`:

```
precision_map   = {"3_trt_tf32": "tf32", "4_trt_fp16": "fp16", "4_trt_bf16": "bf16"}
cal_method_map  = {"5_trt_int8_minmax": "minmax", ...}
Stage 6 mixed   = strategy "a"/"b" + calibrator_method="entropy" (same fallback as cli.py)
```

`TensorRTEngine.__init__` derives `self._engine_path` internally from `(model_token, precision,
calibrator_method, mixed_strategy)`; the caller passes only `engine_dir + precision`. The script
checks `engine._engine_path.exists()` after construction to fail-fast with exit 2 if the cached
`.engine` file is absent.

## Selected (model, stage) Triplet Logic

1. `("rt-detr", "1_pytorch_fp32")` — hardcoded baseline.
2. `("rt-detr", _select_rt_detr_best_mixed(results_root))` — reads `6_trt_mixed_a.json` and
   `6_trt_mixed_b.json`, picks higher `map_50_95`; tie-break alphabetical (a wins).
3. `_select_fastest_yolo(results_root)` — reads `throughput_fps` from 4 JSONs
   (yolo11l + yolo26l) x (mixed_a + mixed_b); picks highest; tie-break alphabetical on
   `"{model}_{stage}"`. Warns and skips missing/non-numeric entries; exits 2 only if all 4 fail.
