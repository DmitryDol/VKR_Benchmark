### Letterbox transform formula

Single scale factor: `scale = min(target_w / orig_w, target_h / orig_h)`

Coordinate mapping from COCO xywh to tile pixels:
- `x1 = int(x * scale + pad_x)`
- `y1 = int(y * scale + pad_y)`
- `x2 = int((x + w) * scale + pad_x)`
- `y2 = int((y + h) * scale + pad_y)`

where `pad_x = (TILE_W - new_w) // 2` and `pad_y = (TILE_H - new_h) // 2`.

### Canvas geometry

- Tile: 500 x 400 px (TILE_W x TILE_H)
- Spacing: 6 px (TILE_SPACING_PX)
- Canvas: 1524 x 1224 px (3*500 + 4*6 wide; 3*400 + 4*6 tall) — matches spec target ~1500x1200
- Background: white (255, 255, 255)

### Determinism strategy

1. All iteration order from locked `SAMPLE_IMAGE_IDS` sorted tuple.
2. `cv2.imwrite(..., canvas)` — PNG has no embedded timestamps by default.
3. Unconditional Pillow re-save (`Image.open().save(..., "PNG", optimize=True)`) strips any residual platform-specific PNG metadata chunks.
4. Verified sha256-stable: `9051d5707349a03b12f069d7e6716a39cf02525dd87b01d0fe551a72d7af1246` identical across two consecutive runs.
